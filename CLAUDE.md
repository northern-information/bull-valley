# Bull Valley Shadow Wars

An adventure RPG set in a hauntological Bull Valley, Illinois. 3D first-person in the browser, WASD + mouse, PS1 aesthetic. The engine was ported from forgotten-industries' ground-survey spike (provenance sha in the first commit); the spike's branding is gone — this is Bull Valley Shadow Wars. The valley is one persistent world that everyone online shares; its players are **raiders**. The raid (a session that ends at an extract) is set aside for now and will come back; until then nothing in the game starts or ends a raid.

## Commands

- `npm run dev` — Vite dev server on port 5174. The Cloudflare Worker and its Durable Object run beside it in workerd (`@cloudflare/vite-plugin`), so this is the whole stack: open two windows and they meet in the valley. Dev state lives in `.wrangler/state`
- `localhost:5174/akashic` — dev-only asset viewer (`akashic.html`, not in the build): one asset at a time through the game's PS1 pipeline, ←/→ to cycle, `#<id>` deep links, anything that moves on its own plays (A holds it; an asset registers its motion with `assets.ts` `setMotion`), hook `window.__akashic` (ids, select, setView, animate). Check asset edits here before a raid.
- `localhost:5174/akashic#map` (or `M` in Akashic) — the map editor: the survey from above over a hillshade of `terrain.png`, every layer toggled on its own. Drag to pan, scroll to zoom, click to select (the panel on the right names it, sets a road's class or water's kind, measures it); drag a point to move it, drag a selected feature (or any fuel point) to move it whole, double-click an edge to add a point, Del removes the point (Shift-Del the feature), arrows nudge, `N` draws a new feature on the chosen layer (Enter ends, Esc cancels), ⌘Z/⌘⇧Z, ⌘S saves. Saving POSTs the survey to the dev server (`vite.config.ts` `akashicMapSave`), which checks it (`mapedit.ts` `isGeo`, the frame unchanged) and writes `geo.json` back minified; under `--mode test` it refuses. Bump `PROTOCOL_VERSION` when a save moves where things are placed (rule 1). Hook `window.__akashic.map`
- `npm run build` — type check, then production bundle (`npm run preview` serves it): `dist/client/` and the Worker bundle with its generated `wrangler.json`, which `wrangler deploy` is pointed at through `.wrangler/deploy/config.json`
- `npm run typecheck` — `wrangler types` (writes the gitignored `worker-configuration.d.ts`), then strict `tsc -b` over `src`, `tests`, the TS configs, and `worker/`
- `npm run deploy` — build, then `wrangler deploy` to https://bvsw.net (a Workers Custom Domain, declared in `wrangler.jsonc` `routes`; https://bull-valley-shadow-wars.tyler-cbe.workers.dev stays on as a fallback). www.bvsw.net, bvsw.gay and www.bvsw.gay are a second Worker, `worker/www.ts` with `wrangler.www.jsonc`, that 301s every request to the same path on the apex (each host a Custom Domain there, so its zone must be on the Northern Information account); the deploy workflow ships it after the game. Deploys go through GitHub only, never from a machine: `.github/workflows/deploy.yml` runs it after a green CI run on `main`, with the organization's `CLOUDFLARE_API_TOKEN` secret and the Northern Information account pinned in `wrangler.jsonc`; a `workflow_dispatch` from `main` also deploys
- `npm run lint` / `npm run lint:css` — ESLint (typescript-eslint, type-aware: mark a fire-and-forget promise with `void`; it generates the Workers types first, since the Worker files need them) and Stylelint
- `npm test` / `npm run test:watch` / `npm run test:unit:coverage` — vitest unit tests (`tests/unit/`) and the Worker tests (`tests/worker/`, mock sockets, a stub `cloudflare:workers`, and `stubs/d1.ts`, a D1 on Node's own SQLite with every migration applied, so the D1 stores run their real SQL); coverage lists every file in `src` and `worker`, though a file no test imports reads 0 of 0 (so 100%): give any module under a floor a test
- `npm run test:e2e` — Playwright (`tests/e2e/`) against its own Vite dev server on port 5175 in `--mode test` (a fresh valley and accounts database every run, shadow maps off, and the valley runs but is never drawn: CI draws WebGL in software, so specs read the game through `window.__bv`, never its pixels); never against `preview`, since the dev hooks exist only in dev builds. First run: `npx playwright install chromium`
- `npm run pretty` — prettier (sorts imports too); run before every commit. `npm run format:check` checks without writing
- CI (`.github/workflows/ci.yml`) runs on every PR to `main` and every push to `main`: format, lint, types, unit tests with coverage (the pure modules and every Worker file have a per-file floor in `vitest.config.ts`), build, and e2e. The e2e job runs in the Playwright Docker image as three parallel jobs: the `@raid` group (`world.spec.ts`, the one-page walk through the valley; the tag and the job keep their name), the `@valley` group (the two-page specs, which boot two games each), and every other spec
- `npm run db:migrate` — apply `migrations/*.sql` to the dev server's local D1 (`bull-valley-accounts`, the accounts behind `/auth`); run it once on a fresh checkout and after adding a migration. The deploy workflow applies them to production before each deploy. Local secrets go in a gitignored `.dev.vars` (see `.dev.vars.example`); none are needed, since a dev server signs sessions with a fixed dev secret and offers the Dev provider (`/auth/dev/form`). Production secrets (`JWT_SECRET`, each provider's client id and secret) are set once with `wrangler versions secret put`
- `npm run copy:ai` — list the lines in `COPY.toml` still marked `by = "ai"`
- `npm run images` — regenerate `public/favicon.ico` and `public/apple-touch-icon.png` from `public/favicon.svg`, and the link-preview card `public/og.png` from the logo (needs ImageMagick 7, `brew install imagemagick`)

## The MVP loop

Spawn at the gas station with your wallet (a new account starts with $40), or wherever your account last stood on foot. Shop the Citgo. Matthew Marx's white Chevy is parked by the spawn Citgo, Marx reading at the tailgate; he reads for five minutes, then crosses Lake Avenue to the field between the road and the corn maze and does donuts for five, then drives home and reads again, over and over, and anyone arriving in the valley while he is at his donuts brings him straight home. Climb into the bed (`E`) and a 60-second countdown starts for everyone; when it runs out he takes whoever is in the bed on the joyride out through the valley and home again, and lets them off at the Citgo. Hop out (`E`) anywhere. `T` whistles for him from anywhere while his bed is empty: he drives to you, you climb in, and he drives you home. Find cabbages in the wilderness and they go into your pack, under Loot. Pickups, the Citgo shelves and whatever lies dropped all come back with the day, at midnight Central. Tab opens the pack over the valley with the pointer free, on its Consumables tab (Loot, where berries and cabbages go, and Materials sit beside it; `A`/`D` switch): hovering an item shows its card, `E` uses it, `1`–`9` puts it on the hotbar along the bottom of the screen, whose number keys use it from then on, and `X` drops one (the open pack or bottle, or one of anything else) a little ahead of you, Shift-`X` the whole stack. Anyone can take a drop up with `E`, as with any pickup; drops lie there until the day turns. Geometrie, the raider's state of mind, sits in the lower right as a red triangle: its top corner lights the higher you get (a joint), its lower right the more stimulated (cigarettes, the energy drinks), its lower left the drunker (beer, liquor; Four Loko does both, and water sobers a little); each fades on its own. Anything smoked or drunk also blurs the view for a second and then trails it for as long as it lasts (a cigarette while it smokes, the joint two minutes, each drink its own). Shadowmen cross the valley around every raider, the same ones for everyone, and show on the scope (`Q`); one that passes close rushes, and its touch puts you back at the spawn Citgo with everything you had. Every raider carries a flashlight in the left hand: the left button raises it and turns it on, and again puts it down; a shadowman held in anyone's beam for half a second bursts into black mist and skulls, for everyone, and leaves 3 to 20 dimes lying where it stood (`CONFIG.shadowmen.dimes`); anyone can take them up with `E`, like a drop, and they go into the wallet at 10¢ each, never the pack, with a line in the log. A step from its dimes it leaves a tombstone carved with the name it is given then (the Bull Valley Scaduscope's folklore names, carried over from forgotten-industries into `names.ts`), seen by everyone; the tombstones stay when the day turns, the oldest going past `CONFIG.graves.max`. An item used from the pack or the hotbar comes up in the right hand the same way, and goes down again. At the heart of the corn maze six more berry bushes ring the portal, each with a berry a day for every account like the one at the spawn Citgo, and the Caretaker keeps the maze: a hooded shade with a cold lantern that floats down the paths, out to a random corner and home to the heart by turns. One that sees you in the maze (or feels you very close) hunts you down the paths, faster than a walk and slower than a sprint, and its touch is a strike like a shadowman's. One flashlight does nothing to it; two raiders' beams on it at once for a second or so unmake it, leaving two bars of gold bullion (one troy ounce each) lying side by side where it was (`CONFIG.caretaker.bullion`), each a drop anyone can take up with `E` into the pack, under Loot, and it forms again at the heart three minutes later. The valley runs as a live service, one season at a time: Season One is **The Caretaker**. Every raider whose beam was on the Caretaker as it came apart is credited with the unmaking, and the fifth pays $100 into the wallet and a carton of Marlboro Reds (ten packs) into the pack, once. A banner sweeps across the view when the season goes live (the first Begin), at each unmaking and when the season is done; a tracker in the upper right and a card on the intro and pause overlay keep the count. Beside the spawn Citgo, Gron stands under his own raincloud by the berry bush; talking to him (`E`) changes your name and your character, any time. The Bull Valley Cabbage Stand is set up on the same lot, across the pumps from the sign: scenery only. Past the lot's far end, across Lake Avenue from the corn maze, a green BMW sits nosed into a tree where it left the road, smouldering, its hazards still blinking: scenery too (`assets.ts` `buildWreck`, placed by `world.ts` at `CONFIG.wreck`). Under every Citgo sign, Moab Coldë, a burning skeleton in a strapped red trench coat, stands with his back to his burning skeleton horse, facing the lot; `E` beside him and he says his one line in the chat log. A raider carrying gold bullion (Loot; the Caretaker leaves it when unmade) who does not wear the Flaming Halo hears his offer as they come into his reach, and the prompt names it: `E` trades one troy ounce for the halo, a ring of gold burning with his fire that floats over the raider's head for good, seen by everyone in the valley (and on Gron's turntable).

## Multiplayer

One Cloudflare Worker serves the bundle and routes `/ws` to one Durable Object, `ValleyDO`, named `bull-valley`: everyone online is in the same valley and shares one persistent world. Each socket's player lives in its attachment (WebSocket Hibernation API); the world lives in the object's storage, and a storage alarm wakes it for Marx's next change and the day's turn while anyone is online. The client sends a state frame (`x y z yaw pitch pose riding light`, light being the flashlight up and on) at most `CONFIG.net.sendHz` a second and only when it changed; peers are drawn `CONFIG.net.interpolateMs` behind the present, between their last two frames. Same origin, no CORS. If the socket never answers, the game plays alone and the valley is the player's own, Marx's day included (the client runs `marx.ts` against the wall clock).

Chat is one channel for the whole valley, live only: Enter opens the field in the lower left (every key types into it until Enter sends or Esc pauses), a `chat` frame carries the line, and the valley sends it back to everyone, the sender included, under the name it holds and with its own timestamp. Nothing is stored. A line starting with `/` is a command answered in the typer's own log and never sent (`chat.ts` `chatCommand`): `/online` names everyone in the valley. Beginning to play says how many others are in the valley, and a raider joining says their name. The text rules (`normalizeChat`, `CHAT_MAX`) are `protocol.ts`'s, and the valley nacks past 5 lines in 10 seconds. Every line in the log carries its local `HH:MM` (the valley's timestamp for a raider's line) and is inked by who said it: raiders blue, NPCs gold, the game's own lines eggshell. Older lines thin out toward the top. The log scrolls with the wheel or PageUp/PageDown (`bindings.ts` `CHAT`) while the field is open, and on hover while paused.

Sign-in is required. The Worker's `/auth` routes (`worker/auth.ts`) sign raiders in with Google, Discord or GitHub (OAuth with PKCE; a Dev provider on dev servers only) and keep the session in httpOnly cookies: a 15-minute access token, a 30-day refresh token. The game is private: a new raider is held as a pending signup until they say the magic word (checked by the Worker alone, `worker/auth.ts` `isMagicWord`, never shipped to the client; a wrong one keeps the signup pending), then chooses a username (3 to 16 letters, digits or underscores, unique without regard to case). Gron, the hunched NPC beside the berry bush, changes it any time (`PUT /auth/username`) and changes the raider's character too; a `rename` frame then has the valley read the new username from D1 (never from the client), an `appearance` frame carries the new outfit, and everyone gets a `peer-updated` frame. Accounts live in D1 (`bull-valley-accounts`, `migrations/`), and so does what each account looks like: the character and guitar finish chosen at the select or at Gron are saved with `PUT /auth/look` and come back in `/auth/me`, so they follow the raider to any browser; the hotbar is kept the same way (`PUT /auth/hotbar`, the `accounts.hotbar` column). Nothing the game keeps lives in the browser's storage. The Worker reads the access cookie on the `/ws` upgrade and stamps the account and username on the request it forwards; the client never sends a name, and a `hello` with no stamped account is closed `unauthenticated` (4007), which sends the player back to sign in rather than into the valley alone. The client refreshes the session before every socket open. `/auth/me` always answers 200, and so does `/auth/refresh` unless it is rate limited, so a signed-out visitor is not an error.

The shared world's rules are `src/sharedworld.ts`, a pure reducer the Worker runs and `tests/unit/sharedworld.test.ts` pins. Every action first settles what was due by now (the day's turn, Marx's next changes), then acts. The world is persistent (rule 1): the first build to arrive opens it, it is kept in storage whoever comes and goes, and only a build on a newer protocol (`SharedWorld.version`) opens it afresh. Where each account last stood on foot is kept (`Valley.places`, rule 2) and comes back in the welcome (`place`), which puts the raider there. Matthew Marx's truck is the valley's (rule 3): a chain of legs stamped with server times (`marx.ts`: parked with Marx reading, donuts, the joyride, called to a whistler, the ferry home), each moved on by `settleTruck` when it is due; the valley never knows the roads, so the hello tells it where the truck parks and how long the joyride takes (`TruckRoutes`), and it reckons any other drive generously. Every client drives the same leg against the same clock (`truckplan.ts` `planLeg`, `Truck.follow`). A `board` frame puts a raider in the bed (the countdown starts with the first), `hop-out` takes them out, and `call` whistles (rule 5: an empty truck only, one at a time; boarding the truck you whistled is the ride home). Pickups are shared by index into `world.pickups`, first to ask wins (rule 4), and every pickup, a cabbage included, goes into the pack. The day turns at midnight Central (rule 6, `daily.ts`): the pickups come back, the shelves fill, the drops go. The shadowmen are the valley's too (rule 11): while anyone is placed in the valley it steps one field `CONFIG.shadowmen.tickHz` times a second (`stepShadows`, a timer that keeps the object awake until no one is left), crossing the bubble round every raider, and sends all of it in a `shadowmen` frame each step; clients draw it a beat behind the present (`shadowsync.ts`). It rushes only a raider on foot and out of the bed, a touch sends that raider alone a `struck` frame, and it burns in any raider's beam, aimed from their state frame (`shadowmen.ts` `beamFrom`). Each burst leaves a drop of dimes (`drops.ts` `DIMES`, how many drawn by the valley with `dimesFor` and spilled with a `spill` action, a `spilled` snapshot); a `take-drop` of dimes pays the wallet (`Reduced.earn`, `PackStore.earn`) instead of the pack. Each burst also leaves a tombstone (rule 16): the valley names it with `graves.ts` `burialsOf` and passes the burials in the same `spill` action, and `WorldWire.graves` carries every one; they outlast the day's turn. Played alone, the client spills its own and buries its own (`actions.ts` `spillBursts`). The hello carries each station's place and the survey's size for it, kept in the world. Played alone, the client steps its own field. The Caretaker is the valley's the same way (rule 13): stepped beside the shadowmen and sent in the same frame (`caretaker`, and `unmade` where two beams unmade it), in the maze the hello placed (`MazePlace`, kept in the world); its touch sends a `struck` frame with `by: 'caretaker'`, and it hunts only a raider a shadowman could rush. Where it is unmade the valley spills two drops of gold bullion, a one troy ounce bar each (`drops.ts` `spillsOf`, the same `spill` action as the dimes, which names each drop's kind), into the taker's pack. Played alone, the client steps its own, which one flashlight can never unmake. The season is the account's (rule 15, `season.ts`): `stepShadows` names the accounts credited with an unmaking (`creditedWith`, once per account), and the valley tallies each alone (`blockConcurrencyWhile`), writing the progress and any reward in one D1 batch (`PackStore.score`, the `seasons` table); a `season` frame (`SeasonWire`, `rewarded` when it paid) goes to every socket on the account, a `pack` frame after a reward, and the welcome carries the progress. Every change comes to every client as a whole `WorldWire` snapshot with a reason; `worldsync.ts` reads it for this raider (`settledBy` whether a take, a sale or a drop was theirs, `aboard`, `seatOf`, `countdown`, `newLeg`), and `valleysync.ts` applies it. The Citgo shelves are shared too (rule 7): the valley holds every station's stock unit by unit (`WorldWire.shelves`, indexed like `world.fuelPoints`; each item a row of on-the-shelf flags, one per slot), a `buy` frame asks for the unit the buyer is looking at and the `bought` snapshot settles the race; cash is the account's wallet in D1 (`wallets`, a new account starts with $40); a buy runs alone in the valley (`blockConcurrencyWhile`), which reads the wallet, refuses a sale it does not cover, and charges it and fills the pack in one transaction (`PackStore.purchase`), so a failed write never takes the cash without the item. The client settles the sale locally (`shop.ts` `settle`) once the valley confirms it, and the valley's `pack` frame (the pack and the cash) has the last word. A client whose station count differs is turned away like one whose pickups differ. The berry bushes are the valley's too (rule 8): the one at the spawn Citgo (bush 0) and the ring at the maze's heart (1 to 6, `CONFIG.maze.bushes`), one berry a day each per account; a `collect` frame names the bush, the `daily` reply says whether a berry came off it, and the welcome carries which bushes the account has had today's berry off. The valley remembers only the accounts that have had today's berry off each bush (keyed by `sharedworld.ts` `bushKey`), so two sockets on one account share one berry a bush. Every item a raider carries is their account's pack, in D1 (`packs`, `worker/d1packs.ts`), and the valley alone writes it (rule 10): the reducer says what goes in or out (`Reduced.pack`: a berry, a pickup, a unit bought, a drop taken up) and a `use` frame takes one out; the welcome carries the pack, and every change sends a `pack` frame to each socket on the account. The client applies its own change at once and takes the valley's pack as the truth when it lands; played alone, the pack starts fresh and nothing is kept. Drops are the valley's too (rule 12): a `drop` frame names the kind and how many, the valley sets it down ahead of where the raider's last state frame put them (never where the frame says, `drops.ts` `dropSpot`), and it stands only once the account's pack has given the units up (`setDown`, alone in the valley like a buy). `WorldWire.drops` carries every drop with its id, and a `take-drop` frame asks for one, first to ask wins. The hello carries every pickup's kind and count (`PickupSpec`), so the valley knows what a take is worth. Moab trades cosmetics for what the pack holds (rule 14, `cosmetics.ts`): a `trade` frame names the offer, the valley reads the pack, refuses a trade it does not cover or a cosmetic already had, and takes the price and writes the cosmetic in one transaction (`PackStore.trade`, alone in the valley like a buy; D1 `cosmetics`). The account's cosmetics ride in the welcome and every `pack` frame, and on each `PeerWire` (read from D1 on the hello, never from the client); a trade sends everyone a `peer-updated` frame so the halo shows. Account ids never go on the wire. Shared moments are server timestamps read through `clock.ts`, so every client agrees where the truck is. A client whose `world.pickups` differ from the world's, in number or in any pickup's kind or count, is turned away (4005). Positions are not compared, so bump `PROTOCOL_VERSION` whenever placement changes: a new protocol opens the world afresh.

Dev only: `?valley=<id>` picks another Durable Object, so parallel e2e specs never meet; `beginRaid` in `tests/e2e/fixtures.ts` gives every page a fresh one unless a spec passes its own, and calms it (below). The Worker stamps dev-server sockets, which unlocks the `dev` frames (`hurry`, behind `__bv.hurryTruck`, brings Marx's next change to a few seconds from now; `shadowman`, behind `__bv.placeShadowman`, stands one still at a spot; `caretaker`, behind `__bv.placeCaretaker`, moves the Caretaker to a spot, where it floats still until it has someone to hunt; `calm`, behind `__bv.calm`, keeps the crossing shadowmen from rushing anyone, so only the ones a spec places do; `grant`, behind `__bv.grant`, puts items in the raider's pack; `reset` opens the world afresh). After a teleport, a spec waits for the valley to hear where the raider is (`heardWhere`) before placing one: a shadowman far from every raider the valley knows is gone in its next step. Production ignores the parameter and the frames.

## Module map

Strict TypeScript throughout. The map (`public/data/bull-valley/`: `geo.json` and the `terrain.png` heightmap) is the game's own, committed and edited by hand; nothing fetches or regenerates it. Shapes that cross modules (world points and heights, geo.json, items, pack grid entries) live in `src/interfaces.ts`; types one module owns stay in that module.

- `src/interfaces.ts` — shared types only, no runtime code
- `src/toml.d.ts` — the type of a Vite `?raw` import, for `copy.ts`'s `COPY.toml`
- `COPY.toml` (repo root) — every player-facing line, each with `text` and `by` (`"ai"` or `"tyler"`); `{name}` placeholders. `src/copy.ts` loads it (Vite `?raw`, so it ships in the client and the Worker) and exports `copy(key, vars)`; `src/copybook.ts` is the pure parsing and filling, shared with `tests/e2e/copy.ts`, which reads the file from disk. `tests/unit/copy.test.ts` fails on a key the code asks for that the file lacks, and on an entry nothing asks for. Modules the e2e specs import (`bindings.ts`, `account.ts`) must not import `copy.ts`: Playwright cannot load `?raw`
- `src/protocol.ts` — pure: the wire protocol, imported by the client and the Worker (frames, close codes, the shown-name rules the stamped username must pass, `parseClientMessage`)
- `src/sharedworld.ts` — pure: the shared world's rules as a reducer over the valley (rule 1: the persistent world, 2: where a raider comes back, 3: Marx's truck, 4: pickups, 5: the whistle, 6: the day's turn, 7: the shelves and the wallet, 8: the berry bushes, 9: Gron, 10: the pack, 11: the shadowmen, `stepShadows`, 12: drops, 13: the Caretaker, 14: Moab's trade, 15: the season, 16: the tombstones), and `wakeAt`, when the valley next needs waking
- `src/marx.ts` — pure: Matthew Marx's day as a chain of legs stamped with server times (parked and reading, donuts, the joyride, called, the ferry home): `settleTruck` moves it on through what is due, `board`, `hopOut`, `call`, `arrive` (home from his donuts for an arrival) and `leave` change it, `nextChange` says when it moves on its own, and `TO_DOOR` is his walk from the tailgate to his door. The valley and a client playing alone both run it; tune it in `CONFIG.truck`
- `src/truckplan.ts` — pure: what a client draws for a leg (`planLeg`: the road, the speed, from when, whether Marx walks to his door first, whether the drive ends parked at home), where a leg cut short left the truck (`approachStart`), the joyride out and home (`joyrideRoute`) and how long it takes (`joyrideMs`, for the hello)
- `src/worldsync.ts` — pure: the client's reading of a `WorldWire` snapshot: `settledBy` whether a `taken`, `bought`, `dropped` or `drop-taken` snapshot went to this raider; `aboard`, `seatOf` the bed seat, `boardable` whether the truck is ours to climb into, `countdown` (and `clockText`) the seconds until Marx leaves, `newLeg` whether the truck has a new leg to drive
- `src/cosmetics.ts` — pure: the cosmetics a raider can wear over a character (the Flaming Halo), each priced in pack items, and what Moab offers a raider (`moabOffer`: the first he lacks and can pay for). `assets.ts` `buildFlamingHalo` draws the halo and `figure.ts` `attachCosmetics` puts it over the head; peers, Gron's turntable and Akashic (`halo-worn`) wear it
- `src/caretaker.ts` — pure: the Caretaker (sharedworld rule 13), in the maze's own metres: the paths it can walk (`mazeMap`, the cells the heart reaches), line of sight and passing room against the corn (`clearBetween`), the way down the paths (`routeTo`), and `stepCaretaker` (patrol out and home by turns, hunt, touch, the two-beam burn, forming again). Tune it in `CONFIG.caretaker`
- `src/caretakerrig.ts` — the Caretaker as seen (`assets.ts` `buildCaretaker` on `ground.at`, turned to the player): the valley's drawn a beat behind the present from the shadowmen frames, or played alone its own, stepped here; it hands `loop.ts` its strike, where it was unmade, and its blip on the scope
- `src/season.ts` — pure: the season (sharedworld rule 15): `SEASON` (Season One, The Caretaker: the goal and the reward), `tally` (one more unmaking, and the reward when it reaches the goal, paid once), `shownKills`, `newsOf`
- `src/seasonhud.ts` — the season as seen: the tracker in the upper right, the card `hud.ts` puts on the intro and pause overlay, and the banners (`announce`, one at a time; `live`, `unmade`)
- `src/drops.ts` — pure: dropped items (sharedworld rule 12), the dimes a burst shadowman leaves (`DIMES`, `isCash`, `dimesFor`, rule 11), the Caretaker's gold bullion (`GOLD_BULLION`, rule 13), and what one step of the valley leaves lying (`spillsOf`): how much one drop takes (`dropAmount`: the open container or one of anything else, or the whole stack), where it lands (`dropSpot`: ahead of the raider, spread round a small circle by id; tune it in `CONFIG.drops`), and what taking it up leaves (`takeUp`). The valley's reducer and the valley played alone both run it
- `src/names.ts` — pure: the shadowmen's folklore names, the Bull Valley Scaduscope's (`forgotten-industries` `src/assets/js/bull-valley-scaduscope/names.js`) word for word: `generateName`. Carved on the stones like trade dress, so not in `COPY.toml`
- `src/graves.ts` — pure: the tombstones burst shadowmen leave (sharedworld rule 16): `burialsOf` names the bursts, `graveSpot` stands each a step off its dimes (`CONFIG.graves.offset`), `bury` lays them and lets the oldest go past `CONFIG.graves.max`. ## Typography

IBM Plex Mono everywhere (`public/fonts/IBMPlexMono-*.woff2`: regular, italic, semibold and bold, the Fontsource latin subset, OFL), self-hosted; every page preloads regular, semibold and bold, and italic loads on demand; the tokens are `--bv-font` and `--bv-text-size` (1rem) in `index.html`. `boot()` awaits `fontsReady()` before it builds any DOM, and the face is `font-display: block`, so no text ever paints in a fallback and reflows; canvas UI text (the scope, peer name tags) uses `MONO` from `canvas.ts` and draws after the gate. The trade dress on packs, cans, medicine and the Citgo signs keeps its own period faces. A label that changes in place must not resize its box: the Begin button stacks every label in one grid cell (`bv-btn--stack`, `Hud.setBegin`), and the account status holds one line even when empty.

## Testing in a browser

- Use `channel: 'chromium'` (full Chromium in headless mode) for Playwright. The default headless shell draws WebGL in software on macOS at about 2 fps, which is too slow to drive the game. On CI there is no GPU at all, so specs take about 3 times longer; `playwright.config.ts` gives them longer timeouts when `CI` is set.
- Boot runs colophon → main menu → (account step) → character select → intro. Each title layer is black and stacked over the next, and a layer's keys arm only once it is showing: Space starts the colophon and Space skips it, the menu's buttons click (`toMenu` lands there, `toCharacterSelect` presses Die), ←/→ and Enter choose. While the pointer is free a Citgo-red edge glows round the view. The account step shows only from the menu's Create Account (the sign-in card), or straight away for a page landing from a sign-in round trip (`?auth=`, which skips the colophon) that has no account with a username yet (Choose Your Username, or the sign-in card with its error). `?skipSplash` skips the titles in dev with the saved pick; with no session it first signs in a dev raider named "Raider" and comes back.
- Specs sign in before they load the game: `signIn` in `tests/e2e/fixtures.ts` goes through the dev provider with a fresh `freshRaider()` (a tagged username, since parallel specs share one accounts database) and lands on `auth-done.html`; `beginRaid` signs in, then loads `/?valley=…` and `passTitles` drives the select. Two pages that must be two raiders need two browser contexts, since the session is a cookie. Under `--mode test` the dev server keeps its state in `.wrangler/state-test`, which the Playwright server command empties and migrates first.
- Wait for `window.__bv` before you click Begin. `boot()` sets the hook last, after the input listeners. The button reads "Click to Die" as soon as input wiring starts, before the hook is set, so its text is not a ready signal.
- To prove that a refactor changes no asset, render every Akashic asset on `main` and on the branch from the same fixed view (`__akashic.animate(false)`, then `select(id)` and `setView(35, 20)`). Compare the `.ak-stats` text and a hash of the canvas screenshot. Serve `main` from a `git archive` copy with a symlink to this repo's `node_modules`.

## Standing rules

1. The map never includes driveways, private service roads, or buildings. Edit `public/data/bull-valley/` by hand, and bump `PROTOCOL_VERSION` whenever a change moves where things are placed.
2. No GPS EXIF in any media added to the repo.
3. Landmarks are consented or public places only. Keep the consent comments in `src/landmarks.ts`.
4. The `three`/`vite` pins are deliberate: `ps1.ts` patches Three shader chunks via `onBeforeCompile`, and Three minors rename chunks. Upgrading is its own task.
5. `public/data` is intentionally minified; it is in `.prettierignore`.
6. A session of play, when the raid comes back, is a raid, not a run — in code, copy, commits, and docs. Its players are raiders.
7. Nothing stands on the raw terrain. Place and move things with `world.ground.at`, and register any new walkable surface (a floor, a deck, a lot) on the `Ground` in `world.ts` before placing on it.
