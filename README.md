# Bull Valley Shadow Wars

An extraction adventure RPG set in a hauntological Bull Valley, Illinois. First-person, in the browser, on the real topology of the village.

You spawn at a gas station with five minutes to pick a loadout before Matthew Marx's white Chevy pulls out. Ride the bed, hop out where you like, find cabbages in the dark, carry them to the Bull Valley Cabbage Stand, and get out — another station, Mt. Coleman's Keep, or whistle for the truck. Every raid ends one of those three ways.

## Run it

```
nvm use
npm install
npm run dev
```

Vite serves on http://localhost:5174. The keys are in `src/bindings.ts`, which also draws the controls table on the intro card.

The engine began as the ground-survey spike in forgotten-industries; the first commit records the exact source sha.
